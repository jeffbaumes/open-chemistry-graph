# Naming ionic compounds

Name the cation first, then the anion.

- The **cation** keeps the metal's name: Na^+ is sodium.
- A single-atom **anion** takes the ending -ide: Cl^- is chloride, O^2- is oxide, S^2- is sulfide and N^3- is nitride.

No prefixes are used. The charges already fix the ratio.

A **polyatomic ion** is a charged group of bonded atoms that acts as a unit.

| Ion | Name |
|---|---|
| NH4^+ | ammonium |
| OH^- | hydroxide |
| NO3^- | nitrate |
| SO4^2- | sulfate |
| CO3^2- | carbonate |
| PO4^3- | phosphate |

Many transition metals form more than one ion. A Roman numeral gives the charge: Fe^2+ is iron(II) and Fe^3+ is iron(III).

## Worked example: name FeCl3

Each chloride is 1-, and there are three, for a total of 3-. The single iron must be 3+.

**iron(III) chloride**

## Worked example: name Ca(NO3)2

Calcium forms only a 2+ ion, so no Roman numeral is needed. NO3^- is nitrate.

**calcium nitrate**

## Common mistake

Using prefixes such as "di" or "tri". CaCl2 is calcium chloride, not calcium dichloride.
